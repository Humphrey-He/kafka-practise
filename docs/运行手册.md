# 运行手册

这份文档用于约定本项目后续示例的运行方式。当前先作为规划文档，等代码与 Docker Compose 落地后再补齐实际命令。

## 本地环境目标

建议准备两套 Kafka 环境：

- 单节点环境：快速验证 topic、producer、consumer 基础行为。
- 三 broker 环境：验证副本、ISR、`acks=all`、broker 故障、leader 切换。

## 推荐配置文件

```text
configs/
  local.yaml
  cluster.yaml
  sasl_ssl.yaml
```

建议基础字段：

```yaml
kafka:
  brokers:
    - localhost:9092
  client_id: kafka-practise
  version: 3.6.0
  sasl:
    enabled: false
  tls:
    enabled: false
```

## 常用验证命令

创建 topic：

```powershell
kafka-topics --bootstrap-server localhost:9092 --create --topic demo-topic --partitions 3 --replication-factor 1
```

查看 topic：

```powershell
kafka-topics --bootstrap-server localhost:9092 --describe --topic demo-topic
```

生产测试消息：

```powershell
kafka-console-producer --bootstrap-server localhost:9092 --topic demo-topic
```

消费测试消息：

```powershell
kafka-console-consumer --bootstrap-server localhost:9092 --topic demo-topic --from-beginning
```

查看 consumer group：

```powershell
kafka-consumer-groups --bootstrap-server localhost:9092 --describe --group demo-group
```

重置 offset：

```powershell
kafka-consumer-groups --bootstrap-server localhost:9092 --group demo-group --topic demo-topic --reset-offsets --to-earliest --execute
```

## 测试约定

普通单元测试：

```powershell
go test ./...
```

如果 Windows 用户目录下的 Go 缓存权限异常，可以把缓存放到项目目录：

```powershell
$env:GOCACHE=(Resolve-Path .).Path + '\.gocache'
$env:GOMODCACHE=(Resolve-Path .).Path + '\.gomodcache'
go mod tidy
go test ./...
```

集成测试建议使用 build tag：

```powershell
go test -tags=integration ./...
```

集成测试要求：

- 测试 topic 使用固定前缀，例如 `kp_test_`。
- 测试结束后清理 topic 或使用短 retention。
- 不依赖生产 Kafka。
- 不把账号、密码、证书提交到仓库。
