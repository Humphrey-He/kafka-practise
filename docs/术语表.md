# Kafka/Sarama 术语表

## Kafka 核心术语

| 术语 | 说明 | 开发注意事项 |
| --- | --- | --- |
| Broker | Kafka 服务节点 | 多 broker 才能验证副本、ISR、leader 切换 |
| Topic | 消息主题，逻辑分类 | topic 命名应带业务域和环境前缀 |
| Partition | topic 的分区 | 分区是并行度和顺序性的边界 |
| Offset | 分区内消息位置 | offset 只在单个 partition 内有意义 |
| Replica | 分区副本 | 副本提升可用性，但增加存储和网络成本 |
| Leader | 当前负责读写的分区副本 | leader 不可用会影响读写 |
| Follower | 跟随 leader 复制数据的副本 | follower 落后会影响 ISR |
| ISR | In-Sync Replicas，同步副本集合 | `acks=all` 时 ISR 数量直接影响写入可靠性 |
| Consumer Group | 消费者组 | 同一 group 内一个 partition 同一时刻只分配给一个成员 |
| Rebalance | group 成员与分区重新分配 | 频繁 rebalance 会造成消费停顿 |
| Lag | log end offset 与 committed offset 的差值 | 要按 partition 看趋势 |
| Retention | 消息保留策略 | 过短会导致未消费消息过期 |
| Compaction | 按 key 压缩日志，仅保留较新值 | 适合状态快照，不适合完整事件审计 |
| DLQ | Dead Letter Queue，死信队列 | 用于隔离无法处理的消息 |
| EOS | Exactly Once Semantics | Kafka 内链路可通过事务增强，跨外部系统仍需谨慎 |

## Sarama 常用类型

| 类型 | 说明 | 常见用途 |
| --- | --- | --- |
| `sarama.Config` | 客户端配置结构 | 统一设置 producer、consumer、网络、安全参数 |
| `sarama.Client` | Kafka 基础 client | 读取元数据、复用连接 |
| `sarama.ClusterAdmin` | 管理客户端 | 创建/删除 topic、查看配置和 group offset |
| `sarama.SyncProducer` | 同步生产者 | 简单发送、需要立即拿到 partition/offset |
| `sarama.AsyncProducer` | 异步生产者 | 高吞吐发送，需要处理回执 channel |
| `sarama.Consumer` | 普通消费者 | 指定 partition/offset 消费，适合工具和回放 |
| `sarama.ConsumerGroup` | 消费者组 | 业务消费的主流方式 |
| `sarama.ConsumerGroupHandler` | group 消费处理接口 | 实现 `Setup`、`Cleanup`、`ConsumeClaim` |
| `sarama.ProducerMessage` | 生产消息 | 包含 topic、key、value、headers 等 |
| `sarama.ConsumerMessage` | 消费消息 | 包含 topic、partition、offset、key、value、headers |

## 语义速查

| 语义 | 做法 | 风险 |
| --- | --- | --- |
| 至少一次 | 处理成功后提交 offset | 可能重复 |
| 至多一次 | 处理前提交 offset | 可能丢失 |
| Kafka 内精确一次 | 幂等 producer + 事务 + read committed | 复杂度高，仍要处理外部副作用 |
| 业务幂等 | 唯一键、去重表、幂等接口 | 需要业务字段支撑 |
| 单分区有序 | 相同 key 固定进入同一分区 | 热点 key 会造成单分区压力 |
